# Kind Way — accessible navigation demo

A Flutter prototype for older adults who want a calm, reassuring way to plan a trip independently. The UI follows the supplied concept: an illustrated nearby map, large saved-place shortcuts, simple route choices, and step-by-step guidance with a trusted-contact button.

## Features

- Large, high-contrast controls and readable text.
- Home screen with a no-key illustrated map and saved destinations.
- Searchable destination list and a mock voice-search button.
- Easiest-walk, fewest-stairs, and fastest route choices.
- Step-by-step demo guidance, reassurance, and a visible call-contact button.
- Arrival confirmation with a mock safe-arrival message.
- Local demo data; no API keys or extra packages are needed.

## Run in VS Code

1. Install the Flutter SDK and the Flutter extension for VS Code.
2. Open this folder, then run `flutter pub get` in the integrated terminal.
3. Connect a device or start an emulator, then press **F5** or run `flutter run`.
4. Run widget tests with `flutter test`.

This repository contains the Flutter app source and package manifest. If Flutter platform folders are not present, run `flutter create .` once from this folder to generate the Android/iOS runner projects.

## Demo behavior

Voice search, phone calls, and the safety message are intentionally simulated with on-screen feedback. Replace these callbacks and the illustrated map with speech, phone, messaging, and mapping integrations when configuring a real deployment.
